# Requirements

- Candidates pick a topic or Mixed and start a 10-question quiz in two interactions, without an account
- Each answer gets immediate feedback with an explanation and a primary source
- A results screen shows the score and per-topic breakdown; missed questions can be reviewed and retried
- Progress and best scores are kept only in the browser (no backend, no personal data)
- Works on 320-1920px screens without horizontal scrolling and meets WCAG 2.2 AA
- The question bank is schema-validated in CI and every published question is reviewed and cites a source
- Works offline after first load; mobile Lighthouse performance >= 90 and <= 200 KB gzip JS
